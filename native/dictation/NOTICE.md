# Pathway Dictation attribution

Pathway adapts Sotto native capture, keyboard handling, insertion, inference workers, transcript cleanup, and dictionary behavior. Reference: https://github.com/davis7dotsh/sotto at f40309e7c59f2f1308d17d3da755b0485e43d92e.

The native inference build copies dependency notices into engines/notices alongside the executables. Downloaded speech, VAD, and cleanup weights retain the licenses in that directory. Model weights are not bundled with Pathway.
