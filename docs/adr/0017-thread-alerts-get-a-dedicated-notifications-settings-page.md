# Thread alerts get a dedicated Notifications settings page

Settings gains a Notifications page with four sections. Thread alerts edits the four global event
defaults. Project overrides lists searchable logical projects and their effective states. This device
owns sound, custom audio, OS-notification permission, and channel toggles. Quiet hours owns the local
weekly schedule and catch-up summary. Each existing Project Settings page also exposes that logical
project's override, so users can edit it centrally or in project context.
