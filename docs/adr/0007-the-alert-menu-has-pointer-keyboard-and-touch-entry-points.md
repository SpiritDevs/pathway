# The Alert Menu has pointer, keyboard, and touch entry points

Control/Command-hover on a thread bell opens the Alert Menu as a fast desktop gesture. Right-click
opens the same menu with a pointer, Control/Command+Enter opens it while the bell has keyboard focus,
and long-press opens it on touch devices. Ordinary hover only shows a tooltip. The modifier-hover
gesture is an accelerator, not the only way to edit individual event choices.
