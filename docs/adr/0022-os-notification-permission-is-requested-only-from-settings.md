# OS-notification permission is requested only from settings

Pathway requests OS-notification permission only when the user explicitly enables that delivery
channel in Notifications Settings. Startup and thread-bell actions never prompt. Settings displays
Available, Blocked, or Unsupported. If permission is denied or later revoked, the effective channel
is off while the user's preference remains stored for recovery. Desktop offers an Open System
Settings action; web shows browser-specific guidance.
