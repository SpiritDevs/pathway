# V1 uses one bounded local alert sound

Each client selects one sound for completion, permission, user-input, failure, and quiet-hours
summaries. V1 does not assign different sounds to different event kinds. Users can choose System
default, a bundled sound, or a custom MP3, WAV, M4A, OGG, or WebM file. A custom file must be at most
5 MB, at most 10 seconds, and decodable by that client before it is saved. Pathway plays it once and
does not loop, trim, or transcode it. Settings provide Preview and Remove actions. If the saved file
is unavailable, delivery falls back to System default.
