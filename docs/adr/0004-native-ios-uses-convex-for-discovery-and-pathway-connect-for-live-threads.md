# Native iOS uses Convex for discovery and Pathway Connect for live threads

The native iOS client uses Convex as its account and discovery control plane: it supplies the companies and environments available to the signed-in user plus cloud-safe Agent Thread list metadata. Pathway Connect remains authoritative for message history, streaming turns, attachments, approvals, user input, source-control operations, and commands. Agent Threads defaults to one combined list across every accessible company and environment, and each thread retains its company and environment provenance so the app can connect to its owner automatically and later filter the list without changing thread identity. Local-network pairing, manually entered server addresses, and user-managed connection grants are outside the native app.
