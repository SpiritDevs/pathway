# Settings on iPhone and iPad

Open the main navigation menu and tap the gear beside **Pathway**. On iPad with the sidebar layout, use the gear in the navigation rail. Settings opens as a full navigation screen. Use Back to return to your previous view.

Settings groups existing preferences by view:

- **App**: general preferences, appearance, storage and cleanup, and keyboard shortcuts.
- **Agent Threads**: Focus Views, favourite models, notifications, and shared drafts.
- **Tasks**: workflow, labels, automation, and integrations for each workspace.
- **Workspaces**: server connections, companies, people, roles, environments, and providers.
- **Account**: sign out.

Choose the workspace or environment whose settings you want to change. Controls for the current task, such as thread model choices and list filters, stay in their views.
