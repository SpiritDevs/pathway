# Workspace views

The primary navigation includes five workspace tools on web and desktop:

- **Projects** lists your logical projects in a dedicated sidebar. Select a project to open its
  dashboard. Project dashboards currently show a pending screen while their contents are being
  developed; project configuration remains under Settings → Projects.
- **Contacts** keeps names, contact details, work context, favorites, and notes together. Contact
  records are currently stored in the browser on the device where you add them.
- **Time Tracker** records start-and-stop work sessions with an optional project. Timer state and
  completed entries are currently stored in the browser on that device.
- **Files** browses the real files in any Pathway project that has a local workspace folder. Choose a
  project in the title bar, search its paths, switch between list and grid layouts, and select a text
  file to preview it. The view is read-only; edit files through a thread or your local editor.
- **Browser** gives the Pathway desktop app a full workspace for its built-in browser. Choose a thread
  in the title bar to open or continue that thread's browser session, use the familiar preview controls,
  or jump back to the selected thread. Browser sessions remain attached to their original thread and
  environment so agent-driven navigation and remote connections keep the right context.

Drag these buttons in the primary navigation rail to put them where they fit your workflow.
