# Viewing images and videos

In web and desktop, select an image or video file link in a conversation to open the
full-window gallery. Images and videos linked in the same message share a gallery.
Use the thumbnails or next and previous buttons to move between them.

Videos have playback, seeking, volume, and fullscreen controls. Playback stops when
you change gallery items or close the viewer. Arrow keys move between gallery items
unless the video controls have focus, where they control playback. Images retain
zoom, pan, fit-to-window, and copy controls.

Download saves the original file. Video downloads remain available if your browser
cannot play the file's codec. Supported video file extensions are MP4, M4V, MOV,
WebM, and OGV; playback depends on the codecs your browser supports.

Videos opened from the file browser also play in the side panel. Select **Open gallery**
for the full-window view, or **Download** to save the file.
