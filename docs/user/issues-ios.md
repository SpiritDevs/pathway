# Tasks on iPhone and iPad

The Tasks view uses a compact list with a status icon, a single-line title, and an assignee. Choose All,
My tasks, or Triage below the title. The title menu switches workspaces. Search, board layout,
sorting, grouping, filters, saved views, and selection actions are in the task menu.

Touch and hold a row for its actions, including assignment, status, priority, due date, and other
properties. With manual sorting, drag a row to change its order or move it into another status.
The same actions are available in board layout.

Tap an existing task to open its own reading screen, with its properties summarized beneath the
title. The section menu beside the comment bar opens Details, Comments, Attachments, Subtasks,
AI, and Activity. Tap the property summary to open a Properties card; each change saves immediately.
Tap Comment to expand the composer above the keyboard, attach an image, or ask an agent. Collapse
the composer to keep an unsent draft while reading. Subtasks and related tasks open as additional screens; Back returns to
the previous task with its draft intact. The app dock returns when you go back to the task list.
The AI tab shows reviews and linked work, with agent controls on a separate screen.
New tasks open in a spacious creation sheet. Write a title and description, then use the property
chips above the keyboard to set assignment, priority, labels, project, status, milestone, cycle,
parent task, and due date. Scroll the chips sideways to reach more properties. Assignee and label
pickers support search; labels allow multiple selections. The editing toolbar adds images and
Markdown formatting to the description. Tap the arrow to save or the cross to cancel.
The edit button opens the title and description editor for an existing task. You can also attach images to comments.
Deleted tasks can be restored from Recently deleted.

Agent work lets you choose a connected environment, provider, model, and workspace. Start work
creates a linked thread with the task context and images. Discuss first opens a discussion without
changing the task's assignment or status. Investigation shows findings and suggested changes;
you can apply suggestions individually. Comments can mention an agent and show its running or
completed response.

Planning contains milestones and cycles, task assignments, progress, milestone timelines, and
historical scope and completion. Task settings include workflow statuses, labels, company
automation, investigation models, Slack intake, and CSV import.

Task data syncs with the workspace. Agent work, investigation, Slack intake, imports, and historical
milestone data need the relevant environment to be connected. If a connection fails while saving,
use Retry pending changes to resend the same change. The app reports rejected changes and restores
the previous value when a write fails.

The iPad layout exposes the same Tasks views through the sidebar. Compact iPad windows use the
same list layout as iPhone.
