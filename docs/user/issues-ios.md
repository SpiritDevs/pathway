# Issues on iPhone and iPad

Issues uses a compact list with a status icon, a single-line title, and an assignee. Choose All,
My issues, or Triage below the title. The title menu switches workspaces. Search, board layout,
sorting, grouping, filters, saved views, and selection actions are in the issue menu.

Touch and hold a row for its actions, including assignment, status, priority, due date, and other
properties. With manual sorting, drag a row to change its order or move it into another status.
The same actions are available in board layout.

Tap an existing issue to open its own screen. Use the Details, Comments, Attachments, Sub-issues,
AI, and Activity tabs. Sub-issues and related issues open as additional screens; Back returns to
the previous issue with its draft intact. The app dock returns when you go back to the issue list.
The AI tab shows reviews and linked work, with agent controls on a separate screen.
New issues open in a creation sheet. Properties opens an editing sheet for status, priority, assignment, labels, project, environment,
milestone, cycle, parent issue, and due date. You can attach images to issues and comments.
Deleted issues can be restored from Recently deleted.

Agent work lets you choose a connected environment, provider, model, and workspace. Start work
creates a linked thread with the issue context and images. Discuss first opens a discussion without
changing the issue's assignment or status. Investigation shows findings and suggested changes;
you can apply suggestions individually. Comments can mention an agent and show its running or
completed response.

Planning contains milestones and cycles, issue assignments, progress, milestone timelines, and
historical scope and completion. Issue settings contains workflow statuses, labels, company
automation, investigation models, Slack intake, and CSV import.

Issue data syncs with the workspace. Agent work, investigation, Slack intake, imports, and historical
milestone data need the relevant environment to be connected. If a connection fails while saving,
use Retry pending changes to resend the same change. The app reports rejected changes and restores
the previous value when a write fails.

The iPad layout exposes the same Issues views through the sidebar. Compact iPad windows use the
same list layout as iPhone.
