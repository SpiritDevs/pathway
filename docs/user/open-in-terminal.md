# Open in Terminal

In **Settings → General → Open in Terminal**, choose **System Terminal** or **Ghostty**. System Terminal is the default. You can switch back at any time or restore defaults.

In a thread’s environment panel, open the **Open in** menu and choose **Open in Terminal**. Choosing Ghostty in settings changes this action to **Open in Ghostty**, with its app icon. The same action is available in the action palette’s Open in menu.

The terminal opens the thread’s project or worktree directory on the selected environment. For a file, it opens the containing folder. Remote connections launch the app on the environment’s machine.

System Terminal uses Terminal on macOS, Windows Terminal on Windows, and the configured `x-terminal-emulator` on Linux. Ghostty supports macOS and Linux and must be installed on the environment. This preference does not change your preferred editor or the built-in terminal.
