# Queued messages

Messages queued from your phone, desktop, or web app appear above the desktop and web composer. Pending messages stay out of the transcript until they are sent to the agent.

Use Edit to return a message and its attachments to the composer, Delete to remove it, or Steer to send it to the active run. Drag the handle to change the order. Cloud-saved follow-ups can be reordered before the environment accepts them; messages already accepted by the environment can be reordered within its queue. A conversation’s first message stays ahead of its follow-ups.

Controls update as delivery progresses. Steering needs an active run and provider support. Messages still uploading from the sending device cannot be reordered yet. Blocked cloud deliveries offer Retry. If another device changes a message or the environment accepts it during an edit, the app reports the change and keeps the current queue state.
