# Remove a queued message

Select **Remove queued message** beside a message in the queue above the composer to cancel it before it starts.

If another device has already cancelled the message, removing it again clears the stale queue entry. It does not send the message or interrupt the active turn.

## Edit a queued message

Select **Edit queued message** to remove it from the queue and return it to the composer. It stays a draft until you press **Send** again, even if the current turn finishes or other queued messages start. This applies to messages with or without attachments.
