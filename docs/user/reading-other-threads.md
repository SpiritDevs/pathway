# Letting an agent read another thread

Give an agent a thread ID and it can read that conversation. The thread can belong to any project or company on the same environment. It can also be on another environment in any company where you can view environments, such as your laptop when the agent runs on your desktop. Copy a thread ID from the thread menu.

To read a thread on another environment, the agent's environment must be signed in to Pathway Cloud and linked to your account. The other environment must be online. Only threads that already appear in Pathway Cloud's thread list can be found this way. Threads in projects not connected to a company are not included.

Reading does not change the other thread. The connection it uses can only read. An agent can only send messages to, wait on, or stop threads in its own project or company.

Agents working on a company assignment for an AI contact can only read threads in that assignment's project. Other company members can direct those agents.
