# Letting an agent read another thread

Give an agent a thread ID and it can read that conversation. The thread can belong to any project or company on the same environment. It can also be on another environment registered to your Pathway account, such as your laptop when the agent runs on your desktop. Copy a thread ID from the thread menu.

To read a thread on another environment, the agent's environment must be signed in to Pathway Cloud, and the other environment must be online. You also need permission to read environments in the company that owns the thread. Only threads that already appear in Pathway Cloud's thread list can be found this way. Threads in projects not connected to a company are not included.

Reading does not change the other thread. An agent can only send messages to, wait on, or stop threads in its own project or company.

Agents working on a company assignment for an AI contact can only read threads in that assignment's project. Other company members can direct those agents.
