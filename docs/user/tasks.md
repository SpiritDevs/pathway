# Tasks

Tasks is the place to plan and track work across your projects. Open **Tasks** in the main navigation, then choose **All tasks**, **My tasks**, or **Triage**. Switch between a list and a board, filter the work, or save a view you use often.

On web and desktop, the list and board start with the view controls at the top, without a separate page title row.

Choose **New task** to capture work. A task can have a project, status, assignee, priority, labels, due date, milestone, and cycle. Open a task to edit its details, discuss it in comments, attach files, or start work with an agent. Use subtasks for work that needs its own status and assignment, and a checklist for smaller steps.

On web and desktop, **Investigate** runs read-only analysis in an active checkout of the task's project. It uses the project's default environment, or the environment selected in the task's detail pane. Recent task changes must sync to Pathway Cloud before an investigation starts. Its history and cancellation controls use the selected environment too.

Agents can work with tasks the way you do. Ask an agent to file or update tasks; post, edit, or delete its own comments with screenshots and other files from its computer attached; tick off checklists; link tasks as blocking, related, or duplicate; accept or reject triage items; assign tasks to a teammate by name or email; and manage cycles, milestones, labels, and statuses, including their dates and order. Every change an agent makes is attributed to it in the task's history. Agents can attach images, mp4 or webm recordings, and text or JSON files.

On web and desktop, the **Projects** list in the Tasks sidebar shows projects that have tasks. To see the rest, choose **Show … without tasks** below the list, or search for any project. Use **+** beside the search button to add a project. Right-click a project to pin it, create a task in it, open it or its settings, copy its path, rename it, archive it, or delete it. Pinned projects stay at the top, above a pin divider, and stay visible when the list is collapsed. Pins apply to the current device.

Archiving a project hides the project and its tasks and milestones from Tasks. To bring them back unchanged, open **Archived** at the bottom of the list and choose **Restore**. Deleting a project permanently removes it, along with its tasks, milestones, captured emails, and connected automation, from every Pathway app. Files on disk are not touched.

Manage statuses, labels, milestones, imports, and enrichment under **Settings → Tasks**. Slack intake and task automation are available in **Settings → Integrations**. Task due dates can appear in Calendar, and task creation time appears in Time Tracker.

Tasks was previously named Issues. Existing tasks, keys, saved views, links, and history continue to work. **Scheduled tasks** keeps its name for recurring automations.

See [Tasks on iPhone and iPad](issues-ios.md) for the mobile layout and controls.
