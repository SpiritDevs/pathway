# Read conversation history

On web and desktop, opening a long conversation loads its most recent messages and activity first. Older history stays on the environment that owns the conversation until you need it. This also applies when you reconnect to a remote environment.

Scroll to the top of the loaded conversation to retrieve an older page, or use **Load older messages from remote**. Your reading position stays in place as earlier messages arrive. Pages contain up to 50 timeline entries, including tool activity, so a single long-running turn can span several pages.

The conversation index on the left includes earlier messages that have not been loaded yet. Select a marker to retrieve that part of the conversation directly. You can load adjacent pages from there or return to the latest messages without fetching all the history in between.

Loading history does not change the agent's context or delete any messages. If a request fails, the messages you already loaded remain available and you can retry after reconnecting.

The environment must support paged history. Connections to older versions continue to load conversations as before.
