# Letting an agent read or message another thread

Give an agent a thread ID and it can read that conversation or send it a message. For example, an agent can message another thread to start its next step when it finishes. The thread can belong to any project or company on the same environment. It can also be on another environment in a company you belong to, such as your laptop when the agent runs on your desktop. Copy a thread ID from the thread menu.

To reach a thread on another environment, the agent's environment must be signed in to Pathway Cloud and linked to your account. The other environment must be online and running a current version of Pathway. If it runs an older version, the agent is told to update Pathway there before it can read that thread. Reading needs permission to view environments in the thread's company, and sending needs permission to control remote agents there. Only threads that already appear in Pathway Cloud's thread list can be found this way. Threads in projects not connected to a company are not included.

An agent cannot start work with broader access than it has itself. For example, an agent running with approval required cannot message a thread that runs with full access. Waiting on, stopping, and listing threads still stay within the agent's own project or company.

Agents working on a company assignment for an AI contact can only reach threads in that assignment's project. Other company members can direct those agents.
