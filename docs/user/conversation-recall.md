# Referring to earlier conversations

You can ask an orchestrator to find an earlier conversation by topic without supplying its ID. It can search eligible conversations, including archived ones, and read older messages to recover context and decisions. If several conversations match, it may ask which one you mean.

Recall respects conversation membership, history boundaries and project access. Information that cannot be shared with everyone in the current conversation is withheld. Saved explicit preferences take precedence over historical inferences. Forgotten source messages are excluded from agent recall without removing your visible conversation history.

Search works in bounded pages and matches titles and recent messages. A topic mentioned only deep in an unnamed conversation may need a more specific reference to locate.
