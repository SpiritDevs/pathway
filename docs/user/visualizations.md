# Visualizations in conversations

Interactive HTML visualizations appear as cards in the conversation. Select a card to open it in the browser. On desktop, it opens in Pathway’s browser panel; on web and mobile, it opens in your browser.

The visualization loads from the environment that owns its message, including remote environments and inherited conversation history. Connect to that environment to open it. If the file has been moved or deleted, ask the agent to recreate it, then retry.

Code examples containing visualization markers remain code examples. A visualization card does not preserve a permanent copy of the original file.
